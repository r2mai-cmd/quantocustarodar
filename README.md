# Quanto Custa Rodar?

Comparador de custo de uso de veículos.

## V13
- Identidade visual com bomba de combustível + energia/raio.
- Dois carros são o padrão inicial, inclusive no celular.
- Dados não integrados/confiáveis não são exibidos como números na tabela.
- IPVA, manutenção, preço de referência e TCO ficam fora da tabela enquanto não houver integração comparável.
- Aviso de privacidade e páginas de Privacidade, Cookies e Termos.
- `robots.txt`, `sitemap.xml`, canonical, Open Graph e JSON-LD para facilitar indexação.
- Estrutura preparada para futura ativação de Google AdSense sem inserir um ID de publisher fictício.

## AdSense
O projeto está tecnicamente preparado para receber o código do AdSense no HTML, mas a aprovação não é automática. Depois de criar/associar a conta AdSense, insira o código e o ID fornecidos pelo Google e configure o `ads.txt` conforme as instruções da conta. A política de privacidade e o gerenciamento de cookies devem ser atualizados conforme os serviços de terceiros efetivamente ativados.

## Publicação
O `index.html` está na raiz da publicação do GitHub Pages.
